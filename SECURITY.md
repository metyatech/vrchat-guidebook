# Security Policy

## Supported Versions

Only the latest version of this project is supported.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately.
Do not disclose vulnerabilities via GitHub issues or publicly.

Please send an email to [security@metyatech.tech](mailto:security@metyatech.tech) with details of the vulnerability.
We will acknowledge your report and provide a timeline for addressing the issue.

We appreciate your help in keeping this project secure.
